# AI For Management - Corporate AI Training Program

20-slide bilingual deck (English headings, Khmer body text) for the AI For Business
full-day, no-code AI training program for managers.

- `AI-For-Management-Training-Program.pptx` — the deliverable (16:9, 20 slides)
- `src/content.js` — all slide copy (edit here to change wording)
- `src/build.js` — pptxgenjs generator for the split-panel layout system

## Rebuild

```bash
cd src
npm install
npm run build
```

Fonts used in the file: Plus Jakarta Sans (Latin) and Noto Sans Khmer (Khmer).
Install both locally so the deck renders as designed.
