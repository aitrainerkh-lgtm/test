## Intent

A premium 60-second technology explainer: "What Is an AI Agent and How Does It Work?".
It must feel professionally produced, not a slideshow. Continuous motion, a meaningful
visual change every 2-4 seconds, match cuts and object transformations instead of fades.
Story: busy employee (hook) -> prompt becomes AI Agent -> Understand / Plan / Execute ->
uses tools on a computer -> research data -> spreadsheet -> chart -> report ->
AI team (Research, Finance, HR, Reporting agents) -> human review and approval ->
"HUMAN LEADS. AI AGENTS EXECUTE. WORK GETS DONE."

## Customizations

- Khmer narration written with Gemini, checked by hand, voiced with Gemini TTS (natural Khmer, professional, friendly, moderate speed).
- Music generated with Lyria (modern, intelligent, futuristic, professional); ducked under narration.
- Sound design: UI clicks, typing, whooshes, data movement, soft notifications, impacts.
- Kinetic typography in English keywords: AI AGENT, UNDERSTAND, PLAN, USE TOOLS, TAKE ACTION, AI TEAM, HUMAN REVIEW.

## Notes

- Light gray / white backgrounds, dark charcoal type, green and orange accents, glassmorphism, soft shadows, depth.
- No childish robots, no robot emoji, no static AI images, no PowerPoint look.
- Branding: "AI For Business". Only tools named if any: ChatGPT, Claude, Gemini, Copilot.
- People appropriate for a modern Cambodian business environment.
- Currency USD only if any figures appear.
